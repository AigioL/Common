## AigioL.Common
通用类库，代码完全兼容 [Native AOT](https://learn.microsoft.com/zh-cn/dotnet/core/deploying/native-aot/) 与 [Trimming](https://learn.microsoft.com/zh-cn/dotnet/core/deploying/trimming/trim-self-contained)  
所有 [C#](https://dotnet.microsoft.com/zh-cn/languages/csharp) 代码兼容当前 [.NET 标准期限支持(STS)](https://dotnet.microsoft.com/zh-cn/platform/support/policy) 与 [.NET 长期支持(LTS)](https://dotnet.microsoft.com/zh-cn/platform/support/policy)  
少数代码支持 [.NET Framework](https://dotnet.microsoft.com/zh-cn/platform/support/policy/dotnet-framework) 3.5 ~ 4.8.1 与 [.NET Standard](https://learn.microsoft.com/zh-cn/dotnet/standard/net-standard) 2.0 ~ 2.1
